# Proposta Comercial Interativa - DSucesso & Termotech

## Descrição

Esta é uma proposta comercial interativa desenvolvida como uma página web única (one-page) para apresentar a parceria estratégica entre DSucesso e Termotech. A proposta foi criada com foco na experiência do usuário, utilizando design moderno e elementos interativos para engajar o cliente.

## Características Principais

### Design e Visual
- **Identidade Visual**: Cores oficiais da DSucesso (#0030d8 e #9f9f9f)
- **Tipografia**: Fonte Poppins do Google Fonts para legibilidade profissional
- **Layout Responsivo**: Adaptável para desktop, tablet e mobile
- **Animações Suaves**: Efeitos de entrada e transições elegantes

### Funcionalidades Interativas
- **Navegação Fixa**: Menu superior com links para todas as seções
- **Barra de Progresso**: Indicador visual do progresso de leitura
- **Scroll Suave**: Navegação fluida entre seções
- **Tooltips Informativos**: Timeline interativa com detalhes dos trimestres
- **Efeitos Hover**: Cards e botões com feedback visual
- **CTAs Funcionais**: Botões de ação que abrem email e agendamento

### Estrutura da Proposta

1. **Capa**: Apresentação da parceria com título impactante
2. **Introdução**: Contextualização do momento da Termotech
3. **Solução**: 4 fases do programa de 12 meses em cards interativos
4. **Cronograma**: Timeline visual com tooltips informativos
5. **Resultados**: Grid com benefícios esperados
6. **Investimento**: Valor destacado com justificativa
7. **Sobre**: Apresentação da DSucesso e Anderson Mendes
8. **CTA**: Botões de ação para aprovação e agendamento

## Como Usar

### Visualização Local
1. Abra o arquivo `index.html` em qualquer navegador moderno
2. A página funcionará completamente offline
3. Todos os estilos e scripts estão incorporados no arquivo

### Personalização
Para personalizar a proposta, edite as seguintes seções no arquivo `index.html`:

- **Contatos**: Altere o email no botão "Sim, quero aprovar e começar!"
- **Agendamento**: Substitua o link do Calendly no botão de agendamento
- **Imagens**: Substitua as referências de imagem pelos assets corretos
- **Textos**: Modifique o conteúdo conforme necessário

### Hospedagem Online
A página pode ser facilmente hospedada em:
- GitHub Pages
- Netlify
- Vercel
- Qualquer servidor web
